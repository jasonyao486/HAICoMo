# HAICoMo 产品需求 — 0.3.1

日期：2026-10-07。本文件整理已确认的当前产品范围。原始需求保留在本地且不修改；实现与验证分开记录，见 [REQUIREMENTS](REQUIREMENTS.md)。

## 用户与闭环

一个人类用户管理零个、一个或多个 AI agent。流程为建立项目与任务 → 人类或 agent 提交修改 → 人类审阅 → 工作与交接 → 定位交付物 → 人类验收 → 下游解锁 → 归档与恢复。动画、agent 自报完成、客户端退出都不能替代验收。当前不提供多人类账号或多机实时协作服务。

## 项目与数据

默认单窗口多标签，可显式开独立窗口；重复打开同一身份返回原项目。每个工作目录对应一个项目，`.haicomo` 是可双击入口，隐藏 `.haicomo/` 是管理数据。普通打开不恢复已删除入口。恢复、重新定位、同目录新建与独立副本是不同动作；旧数据不能被静默覆盖。跨窗口、后台回调和异步启动都校验项目 ID、epoch 和绑定。

SQLite 由单个 utility process 写入，事务保护审批、审计和实体。v5 项目迁移前自动备份，保留入口及提案协议版本。关闭标签保留必要后台运行和接力；退出释放锁。备份包含管理数据，不包括源代码及交付物文件。网络共享活动数据库和多机同时打开不在可靠性承诺内。

## 管理视图

任务支持名称、描述、日期、父任务、前置依赖、多负责人、状态、进度、交付物、交接说明和任务桌可见性。层级与依赖不得成环，前置及子任务须人工验收后才解除限制。日期与可见性等纯计划修改不撤销验收，影响交付内容的修改要求重新验收。归档独立于完成状态。

侧栏顺序：项目总览、任务清单、修订提案、接力任务（实验）、时间线、前置关系、思维导图、协作办公室、备注与会议、活动记录、协作统计、归档；设置留在底部。logo 下方显示侧栏开关和 `version 0.3.1`，不保留个人预览版字样。

时间线支持拖动和键盘调整，仍校验修订号。思维导图按子树展开并居中父节点；前置关系按拓扑分层，不相连的任务组分开排列。目标数据为 10 个父任务、每个 5 个子任务；节点可放大、缩小、适应、重置、拖动画布、键盘打开。全局缩略视图可牺牲文字大小，不允许节点互相覆盖。公司标志只来自明确分配的模型，不猜测客户端或历史会话的模型归属。

## 协作与执行

Agent 读取快照并投递不可变 JSON、SHA-256 完成标记和事件。应用离线时可继续投递，回执表示接收及审阅结果。相同 ID/内容幂等，异内容拒绝；损坏文件隔离。审批全有或全无，冲突不静默合并。CLI、文件协议和可选 MCP 不能批准、验收或删除人类活动记录。

Codex 使用 App Server，Claude 使用已安装 CLI，沿用用户登录和订阅。仅声明真实可观测的启动、会话、模型、推理、模式、权限、取消能力。其他 GUI 客户端通过打开和复制提示词辅助交接。未知结果不自动重发，不采集模型密钥，不提供跳过权限选项。

接力只做一步；由接力启动的运行不能再作前置。同一前置可扇出。前置完成和延迟/指定时间同时满足后，先事务认领再启动一次；失败、未知、错过均需人工处理。支持暂停、修改、恢复、取消及显式立即执行；应用须运行且项目已加载。文字和可视化共享状态，不让装饰动作影响调度。

## 素材、统计与活动

默认模式为图标头部火柴人；增强模式为手绘环境及十四家族拟人形象。任务桌、替补座位、行走、交谈和爱好均为表现层。非活动页停止动画，减少动态使用静态姿态。渲染失败保留管理及状态列表。

接力增强模式使用三人宽现代工位、双人轻奢沙发。工位左侧笔记本，中央保留主机摆饰，右侧延伸副屏及纸质笔记本、运动水杯；沙发固定俯视正面，坐垫水平朝向用户。

统计仅累计持久化记录和可观测运行时间。复制提示词与真实发送分开统计。活动允许人类永久删除单条，日期旁按钮和二次确认明确“不撤销对应操作”。删除不修改实体、审批、验收、回执或统计，不修改旧备份。历史返工次数独立保存，旧版审计只初始化一次。
