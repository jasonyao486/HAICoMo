# HAICoMo 0.5.0 preview

[Mac Apple Silicon — DMG](https://github.com/jasonyao486/HAICoMo/releases/download/v0.5.0/HAICoMo-0.5.0-arm64.dmg) · [Windows x64 — Setup](https://github.com/jasonyao486/HAICoMo/releases/download/v0.5.0/HAICoMo-0.5.0-windows-x64-setup.exe)

Mac Apple Silicon 与 Windows x64 同步发布 0.5.0。已安装 0.4.0 或 0.4.1 的用户可在“设置 → HAICoMo → 检查更新”中直接在应用内更新。

- **更多智能体可后台调用。** 检测范围新增 Kimi、Grok Bot、DeepSeek Harness、Gemini CLI 与 Qwen Code，共 15 个客户端。凡提供命令行无界面模式的客户端都可后台调用：Codex、Claude Code、Cursor Agent、Kimi、DeepSeek Harness、CodeBuddy、Qoder CLI、Gemini CLI、Qwen Code、OpenCode、GitHub Copilot CLI、Pi。仅当已安装版本的帮助文本列出所需参数时才启用，并标注证据等级（已实测／已在本机核对参数／按官方文档适配未实测）。Codex、Claude Code、Cursor 与 DeepSeek Harness（走 DeepSeek 账号登录，无需 API key）已实测。Grok Bot、WorkBuddy、TRAE 没有命令行接口，仍为打开应用并复制提示词。
- **三阶段并行接力。** 一个接力最多 A → B → C 三个阶段，每阶段最多 3 个任务同时进行；当前阶段全部交付后自动进入下一阶段，中间不需要审阅，后续阶段的提示词带入前序结果摘录。交付物仍需你验收。任一任务未交付就停在本阶段，可只重试停止的任务或标记已处理；从不自动重试。Cursor → DeepSeek 的跨智能体接力已真实跑通。
- **无人值守模式（逐个接力同意）。** 智能体使用各自的自主参数；Codex 的选择题自动选推荐项、工具审批自动批准但拒绝破坏性命令；遇到登录、验证码、额度用完等只能由你处理的事会暂停并发系统通知；每个接力生成决策记录。
- **接力页面。** 文字模式显示完整流程图；可视化模式中工位与三人沙发等宽、上下居中并铺满整行，工位只坐当前阶段正在工作的智能体，每个等待阶段一张三人沙发。新建接力的编辑窗口加宽，三个阶段并排。
- **本地智能体设置。** 检测结果合并在每个客户端一行中，并在本次运行期间保留；可选“打开 HAICoMo 时自动检测”（默认关闭，窗口出现后在后台进行）。检测后路径变更、程序被卸载或移动、登录失效等情况都会在启动任务前提示原因，不会发出任务。
- **数据结构 v6。** 首次打开项目时先自动备份为 `pre-v6` 再迁移；升级后的项目不能再用 0.4.1 及更早版本打开，请把所有电脑都更新到 0.5.0。

English: **More background agents** — detection adds Kimi, Grok Bot, DeepSeek Harness, Gemini CLI and Qwen Code (15 clients). Every client with a headless command line can run in the background, enabled only when its installed help text lists the required options and labelled with its evidence level; Codex, Claude Code, Cursor and DeepSeek Harness (on the DeepSeek account route, no API key) were tested end to end. **Three-stage parallel relays** — up to A → B → C with up to three tasks per stage; the next stage starts automatically once every task of the current stage delivered, with earlier results in its prompt; acceptance stays yours; a stopped task halts its stage for retry or "mark handled", never automatically. A real Cursor → DeepSeek relay completed. **Unattended mode** (per-relay consent) — clients' own autonomous options, Codex questions answered with the recommended option, destructive commands declined, sign-in/quota and other human-only steps pause with a notification, and a decision record per relay. **Relay page** — full flowchart in Text view; equal-width, vertically centred desk and three-seat sofas filling the row, one sofa per waiting stage; a wider editor shows all three stages side by side. **Local agents** — detection results in each client's row, kept for the session; optional detection at launch (off by default, after the window appears); path changes, removed programs and expired sign-ins are reported before any start. **Schema v6** — backed up and migrated on first open; 0.4.1 and earlier cannot open migrated projects, so update every computer.

Users of 0.4.0 or 0.4.1 can update in-app (Settings → HAICoMo → Check for updates). Versions 0.3.5 and earlier: download this release, or enter `https://github.com/jasonyao486/HAICoMo/releases/download/v0.5.0` as the update source once. Windows downloads remain unsigned; in-app updates rely on GitHub HTTPS and the SHA-512 in `latest.yml`.
