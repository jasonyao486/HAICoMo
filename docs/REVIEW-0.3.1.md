# HAICoMo 0.3.1 场景审查

审查日期：2026-10-07。范围是当前源码、隔离数据库与实际 Electron 界面；代码阅读和自动化由本次实现环境执行，不伪装成独立外部审计。真实付费账号、远程机器、Windows 消费者桌面与物理断电不在本机验证内。具体执行结果见 [测试](TESTING-0.3.1.md)和[平台报告](COMPATIBILITY-0.3.1.md)。

## 关键判断

管理闭环、人工审批/验收边界及本地持久化具备系统性覆盖，可作为明确标注平台与签名限制的预发布版本。它不应被宣传为任意 agent 的完全执行控制台，也不应被当作 NAS 上的多机协同数据库。未发现需要通过放宽权限或自动批准来解决的功能前置条件。

## 使用场景

| 场景 | 审查结果与证据 | 实际限制 |
|---|---|---|
| 无 agent | 新建、任务/子任务、日期、备注、验收、重启均走本地闭环；空接力文字提示及两种可视化家具预览 | 不会凭空产生运行时长或模型活动 |
| 单 agent | Codex/Claude fixture 覆盖发现、启动、消息、权限、取消、断开；前台与后台操作分开记录 | 本轮没有重新向真实账号发送工作，不能推断所有客户端版本都兼容 |
| 多 agent | 不可变 inbox、SHA-256 ready 标记、独立提案 ID、原子审阅与幂等回执 | 共享交付物/源代码的内容冲突仍需 agent 或人处理 |
| 离线提案 | 应用关闭时可投递；重开按持久化状态接收，不将缺少回执视为成功 | 无后台服务器替离线应用审批或调度 |
| 修订冲突 | 实体修订号及项目元数据修订保护；跨窗口旧编辑拒绝；批次不部分应用 | 不自动决定相互冲突的业务意图 |
| 异常退出 | utility process 退出后重开数据库；命令 ID 支持显式安全重试；未知发送不自动重发 | 没有物理掉电或磁盘固件故障测试；SQLite事务不能保证外部程序恰好执行一次 |
| 权限与身份 | sandbox renderer、窄 IPC、项目 ID/epoch/绑定；文件/CLI/MCP 不批准或验收；外链固定白名单 | 本地可写文件的程序不是可信身份，不能防恶意同权限进程直接改文件 |
| 交接/接力 | 先认领再启动、一步限制、暂停/恢复、错过和失败人工处理、触发时引用交付物 | 应用需运行且项目已加载；无自动重试或关机调度 |
| 恢复与副本 | ZIP校验、恢复空目录、入口显式恢复、独立身份、迁移前备份 | ZIP 不包含真正的交付物；外部绝对路径需重新定位 |
| 活动删除 | 确认/取消、重新打开、重复命令、跨项目记录隔离、分页、统计保持；旧备份不重写 | 删除是逻辑永久删除，不是安全擦除；旧备份可带回旧记录 |
| 图与小窗口 | 60节点树/依赖布局无节点重叠；适应、缩放、拖动、键盘打开；公司来源仅明确模型 | 长依赖图存在连线交叉；全局缩略时文字必须放大才能读 |
| 四语/主题/减少动态 | key集合一致；设置、授权、图和空状态；实际浅/深色截图 | 翻译由本次实现校对，未做四地真实用户可用性研究 |
| 更新 | 手动 GitHub 下载、固定反馈入口、独立诊断导出；自定义源状态和错误回归 | 未配置可信自动安装渠道，不能把 fixture 下载/安装边界当成签名升级验收 |

## 本轮修复或消除的问题

- 活动记录与返工统计耦合：v5 独立历史计数，迁移后不因删除重新计算。
- 大任务图的重叠及单列拥挤：分层/子树布局、组件打包、缩放和平移。
- Windows 反斜杠与异平台绝对路径：统一引用规则并明确外部文件责任。
- 私人素材被 Vite 一并复制的风险：独立运行素材目录、逐项 hash 白名单构建。
- 旧包缺少 Windows 安装程序：改为原生 CI 构建完整 NSIS，并将结果与人工验收分开。
- 预览字样、侧栏版本位置及反馈缺少目的地：更新为完整版本和 GitHub 链接。
- 首屏缺少接力视觉展示：空可视化保留无人家具场景与原提示，文字视图保持原样。
- 小窗口下项目切换菜单被任务编辑框挡住：修正侧栏菜单层级，并在最小窗口测试草稿保留、切换和保存。
- 客户端检测完成前复制了备用交接命令：检测完成前禁用复制和前台启动，避免预览与实际使用的客户端路径不一致。
- Windows 测试清理与搬移假设：先关闭句柄再清理临时目录；分别验证 Windows 对打开目录的移动拒绝、关闭后移动，以及 macOS 的打开中移动保护。
- 原生 Windows 验证工具的路径与清理问题：runner 临时目录改为等待异步清理；ASAR 检查保留系统路径分隔符；打包程序用 PowerShell 解析实际路径启动。Node 版本对比及最终结果见测试记录。

## 保留的限制与优先级

| 优先级 | 未完成项 | 后续动作 |
|---|---|---|
| 发布验收 | Windows 真机安装、文件关联、托盘、真实 CLI、人工升级 | 按兼容报告清单执行，记录系统/架构/客户端版本及截图 |
| 发布体验 | Mac 公证与 Windows 发布者签名 | 配置证书后验证实际下载、安装及升级失败恢复 |
| 架构 | 多机实时写入和活动 NAS 数据库 | 采用服务器/远程执行设计，不继续扩大文件同步承诺 |
| 产品 | 任意 GUI 会话接管、完整转录、多步工作流 | 根据稳定第三方接口与明确产品决定分别立项 |
| 验证范围 | 长时间真实多 agent 工作、物理掉电、所有旧系统 | 另行进行耐久及平台测试，不从短时自动化推断 |

公开仓库包含可复现测试及合成演示脚本；用户真实项目、旧审阅包和私人账号记录没有作为公开证据上传。
