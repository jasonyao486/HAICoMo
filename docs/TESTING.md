# Testing

Use [TESTING-0.3.1.md](TESTING-0.3.1.md) for the current evidence, [REVIEW-0.3.1.md](REVIEW-0.3.1.md) for scenario review, [FIRST-RUN-0.3.1.md](FIRST-RUN-0.3.1.md) for the simulated new-user journey and [COMPATIBILITY-0.3.1.md](COMPATIBILITY-0.3.1.md) for platform limits.

```sh
npm ci
npm run typecheck
npm test
npm run test:e2e
```

All tests use temporary projects and isolated Electron profiles. Fixtures impersonate provider protocols; they do not bill or prove live third-party service compatibility. The synthetic screenshot demo is generated by `npm run demo -- /absolute/path/to/an/empty/directory`. Do not run tests against a personal project. Failed traces may contain temporary local paths and should be checked before sharing.
