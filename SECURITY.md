# Security

Do not include credentials, project databases, conversation logs or personal paths in public issues. For a suspected vulnerability, use GitHub's private vulnerability reporting option on the repository Security page when available; otherwise ask for a private reporting channel without describing exploit details publicly.

HAICoMo is a local application. Its proposal protocol controls application approval, not other programs with write access to the same files. It does not authenticate self-reported agent identities. Keep one active writer per project. Network shares and file synchronisation are not a distributed database.

Version 0.3.1 uses manual updates. Download only from this repository's Releases page and verify the supplied SHA-256 when needed. The first release is not notarised or publisher-signed; do not disable system security globally to install it.
